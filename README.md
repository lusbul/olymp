# Кіт Буч — олімпіадне програмування, розділи 1–8

Розпакуйте вміст ZIP до кореня репозиторію GitHub Pages із заміною файлів. Відкрито 8 розділів рівня ★, по 5 задач у кожному. Кожна задача має 10 браузерних тестів, Python-редактор та навчальну лабораторію. Тести **не захищені**: зберігаються у JavaScript та доступні через інструменти розробника. Для справді прихованих тестів потрібен сервер перевірки. Python-рушій завантажується з CDN під час роботи сайту, тому потрібен інтернет.
