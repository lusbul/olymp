# Кіт Буч готується до олімпіади з інформатики — v1

## Публікація на GitHub Pages
1. Створіть новий публічний репозиторій GitHub.
2. Завантажте **вміст архіву** в корінь репозиторію (index.html має бути в корені).
3. Settings → Pages → Deploy from a branch → main → /(root) → Save.
4. Відкрийте адресу GitHub Pages. Перше завантаження Python може тривати певний час, потрібен інтернет.

## Що готово
- Головна сторінка, відео Буча, 16 тем і 3 рівні.
- 5 оригінальних задач рівня ★ у темі 1.
- Python runner на Pyodide 0.27.7, окремий Web Worker, введення/виведення.
- Кнопки «Запустити» й «Відправити на перевірку».
- По 10 тестів на задачу, оцінка 0–100%, локальне збереження коду і прогресу.
- Адаптивна верстка для смартфонів.

## Важливі обмеження
- Тести у `js/data.js` **не показані в інтерфейсі**, але **не захищені від перегляду через DevTools**. Це демонстраційна перевірка, не захищена олімпіадна система.
- У цьому релізі немає сервера; для справді прихованих тестів потрібен серверний API та ізольований рушій виконання (наприклад, Judge0).
- Код виконується у браузері учня. Встановлено загальний тайм-аут 20 с, що включає завантаження рушія; це не справжній judge-ліміт часу на окремий тест.
- Python завантажується з CDN jsDelivr. Для роботи потрібне мережеве підключення; при блокуванні CDN запуск не працюватиме.
- Не використовуйте браузерні тести для офіційного оцінювання чи відбору.
