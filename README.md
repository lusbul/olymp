# Кіт Буч — олімпіадне програмування, рівень ★, розділи 1–16

Розпакуйте весь архів у корінь репозиторію GitHub Pages із заміною файлів. Усі 16 розділів першого рівня відкриті: по 5 задач із 10 тестами. Python запускається в браузері через Pyodide та потребує інтернету. Тести не відображаються в інтерфейсі, але зберігаються у JavaScript; справжнє приховування потребує серверної перевірки. Головна сторінка зберігає компактний дизайн без лічильників і зайвих відступів.
