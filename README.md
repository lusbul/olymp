# Кіт Буч — олімпіадне програмування, рівень ★, розділи 1–12

Розпакуйте весь архів у корінь репозиторію GitHub Pages із заміною файлів. Перші 12 розділів доступні; у кожному 5 задач, 10 перевірочних тестів на задачу. Python виконується в браузері через Pyodide та потребує інтернету. Перевірочні тести не відображаються в інтерфейсі, але зберігаються у відкритих JavaScript-файлах; для захисту тестів потрібен сервер. Збережено компактну головну сторінку без лічильників та зайвих відступів.
